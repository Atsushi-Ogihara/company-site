# スカイライン・テクノロジーズ株式会社 コーポレートサイト

ソフトウェア開発・DX支援を手がける「スカイライン・テクノロジーズ株式会社」のコーポレートサイトです。ビルド不要の静的サイト（HTML / CSS / JavaScript）として実装しています。

> **注意:** 本サイトは架空の企業によるデモです。掲載されている会社情報・実績・連絡先はすべてサンプルであり、お問い合わせフォームの送信内容はどこにも送信されません。

## 概要

1ページ構成のランディングページで、以下のセクションで構成されています。

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピー、実績数値のカウンターアニメーション |
| サービス | 受託システム開発 / クラウド・SRE支援 / SaaSプロダクト開発 / AI・データ活用 / DXコンサルティング / セキュリティ診断 |
| 強み | 同社の提供価値の紹介 |
| 実績 | 導入事例の紹介 |
| お客様の声 | 利用企業からのコメント |
| 会社概要 | ミッション、会社基本情報 |
| 採用情報 | 募集職種・カルチャーの紹介 |
| お問い合わせ | 入力バリデーション付きのフォーム（デモ動作） |

### 主な機能

- スクロールに応じたヘッダーの縮小・背景変化
- モバイル向けハンバーガーメニュー
- ニュースバーの自動切り替え（ホバー・フォーカス中は停止）
- スクロールに合わせた要素のフェードイン表示
- ヒーロー内の数値カウンターアニメーション
- お問い合わせフォームのクライアントサイドバリデーション
- 「本文へスキップ」リンク、ARIA属性、`prefers-reduced-motion` への対応などのアクセシビリティ配慮
- レスポンシブレイアウト（スマートフォン〜デスクトップ）

## ブラウザで表示する手順

ビルドやパッケージのインストールは不要です。以下のいずれかの方法で表示できます。

### 方法1: ファイルを直接開く（最も簡単）

Finder でこのフォルダを開き、`index.html` をダブルクリックします。既定のブラウザで表示されます。

ターミナルから開く場合:

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

ブラウザ側から開く場合は、ブラウザのメニューから「ファイルを開く」（macOS: `Cmd + O` / Windows: `Ctrl + O`）を選び、`index.html` を指定します。

### 方法2: ローカルサーバーで開く（推奨）

`file://` ではなく `http://` で配信すると、本番環境に近い挙動を確認できます。Python がインストールされていれば追加のインストールは不要です。

```bash
# このフォルダで実行
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます。停止するには `Ctrl + C` を押します。

Node.js を使う場合:

```bash
npx serve .
```

表示されたURL（通常は <http://localhost:3000>）をブラウザで開きます。

### 補足

- Web フォント（Google Fonts）を外部から読み込んでいるため、オフライン環境ではフォントの見た目が変わります。レイアウトや動作そのものには影響しません。
- 動作確認は各モダンブラウザ（Chrome / Safari / Firefox / Edge）の最新版を想定しています。
- ファイルを編集した後は、ブラウザをリロード（`Cmd + R` / `Ctrl + R`）すれば変更が反映されます。スタイルが古いまま表示される場合はスーパーリロード（`Cmd + Shift + R` / `Ctrl + Shift + R`）を試してください。
